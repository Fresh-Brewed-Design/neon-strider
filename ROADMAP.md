# Roadmap

The roadmap lives in GitHub issues, one per item:

- [Next](https://github.com/Fresh-Brewed-Design/neon-strider/issues?q=is%3Aissue+is%3Aopen+label%3Aroadmap%3Anext+sort%3Acreated-asc)
  (`roadmap:next`): small and ready to build. The scheduled improvement task takes these
  first, oldest first.
- [Unscheduled](https://github.com/Fresh-Brewed-Design/neon-strider/issues?q=is%3Aissue+is%3Aopen+label%3Aroadmap%3Aunscheduled)
  (`roadmap:unscheduled`): later. The improvement task never picks these.

A PR that builds an item says `Closes #N`, so the item closes when the PR merges. An item built
in steps stays open: each step's PR says `Part of #N` and ticks or rewrites that step in the issue.
